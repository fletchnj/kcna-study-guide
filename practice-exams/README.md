## 🎯 Exam Strategy & Tips

- **Pacing**: You have 90 minutes for 60 questions (~1.5 minutes per question).
- **Flagging**: Skip difficult questions and flag them to return at the end.
- **Key Concepts**: Pay special attention to Control Plane components vs Worker Node components, PromQL metric types, CNI plugins, and OpenGitOps principles.
